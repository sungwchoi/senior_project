ubuntu 22.04 를 설치를 했어. > 최근 패키지와 무엇보다 ROS 1 은 이제 지원이 종료 되었기 때문
ROS2 humble 을 다운했고 

Object detection 으로는 지금 yolov8n 을 사용할 생각 (YOLOv4-tiny보다 더 정확하면서도 CPU 추론 속도가 더 빠릅니다. 엣지 디바이스(CPU 기반 소형 장치)를 위해 태어난 최신 경량 모델)

- 1단계: Ultralytics YOLOv8 라이브러리 설치
YOLOv8 핵심 라이브러리 설치 
pip install ultralytics
 
- 2단계: ROS 2 YOLOv8 패키지 설치
ROS2 YOLOv8 패키지 설치 및 클론 그리고 빌드
git clone https://github.com/mgonzs13/yolov8_ros.git # src directory 안에서 

rosdep install -i --from-path src -y # 워크스페이스 제일 위에서 
colcon build --symlink-install

-3단계: 모델 준비 (ONNX로 변환하여 성능 극대화)
Python 셸에서 ONNX로 모델 변환 

from ultralytics import YOLO

# YOLOv8 nano 모델 로드
model = YOLO('yolov8n.pt')

# ONNX 형식으로 변환하여 저장 (CPU 최적화)
model.export(format='onnx')

# exit() 로 파이썬 종료


4단계: 실행 (Launch) 

yolo_bringup/launch 에서 yolov8.launch.py 파일을 수정 해줌 
기존 거는 # 으로 주석 처리하고 똑같은 문장을 아래나 위에 다시 작성함
